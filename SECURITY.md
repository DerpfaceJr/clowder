# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue.

Use GitHub private vulnerability reporting on this repository:
<https://github.com/DerpfaceJr/clowder/security/advisories/new>

Include what you found, the steps to reproduce it, and the version or commit you tested. We will acknowledge the report, work on a fix, and credit you in the advisory if you want credit.

## Supported versions

Only the latest release receives security fixes. Please check that the problem still happens on the latest release before reporting it.
